# 首页轮播改造、后台编排对齐与媒体直接上传

本次变更围绕小程序首页展示、后台首页编排管理和赛事图片录入三条线，目标是让首页内容与设计稿对齐、后台编排能正确生效、运营能直接上传本地图片。

## 已部署情况

- 后端 API（`apps/api`）与后台（`apps/admin`）已部署至生产 ECS 并通过健康检查。
- 小程序前端（`apps/miniapp`）改动已完成并本地构建，需通过微信开发者工具上传发布。

## 一、小程序首页

### 焦点轮播（沉浸式）

- 顶部焦点区由单张静态卡片改为 `swiper` 沉浸式轮播：图片做全幅背景，标题/日期/距离/城市叠加在左侧，底部由左到右渐变蒙版提升对比度，自动播放 + 可手动滑 + 指示点。
- 角标「本期焦点」改为胶囊样式，指向小程序首页默认月份。
- 图片加载失败的兜底逻辑由写死 `[0]` 改为按 `data-index` 精准更新。

### 赛事卡片（event-card 组件，列表/收藏/雷达共用）

- 图片高度由 240rpx 提升至 360rpx，宽高比由 2.9:1 改善至约 1.95:1，缓解横幅图被裁切的问题。
- 图片容器背景由灰色改为白色，未铺满时与卡片更协调。
- 移除卡片底部的「摘要」和「判断理由」两行文字，精简信息层次；同步清理模板、样式与数据，避免死代码。
- 收紧元信息、状态行、底部栏间距，整体比例更协调。

### 首页其他模块

- 「即将开报」由横向滚动改为一行一个赛事的多行列表：左侧报名状态胶囊 + 右侧赛事名/城市，长名单行省略不再被截断。
- 「为你推荐」移除「调整偏好」入口；修复因父级 `nowrap` 导致的卡片文字溢出重叠（卡片设 `white-space:normal` + 赛事名两行截断）。

## 二、后端首页数据分配（discovery/home）

数据现状：已发布赛事总量少（如 11 月仅 5 场），四个分组共用同一批赛事，焦点和「本月值得去」占满后，其余分组为空，导致小程序不显示对应模块。

调整（`apps/api/src/server.ts` 的 `getDiscoveryHome`）：

- 焦点 `focus` 取数由 4 改为 2，给其他分组留空间。
- 「即将开报」放宽筛选，纳入 `signup_open`（报名中），不再只限 `not_started`/`unknown`；且允许与其他分组重复，赛事少时也能展示。
- 「为你推荐」允许与其他分组重复，从全部赛事取数，保证推荐区有内容。

效果：各月份四个分组均有数据，首页全部模块可正常渲染。

## 三、后台首页编排管理（全国发现内容 → 首页编排）

根因：后台默认编辑当月，小程序首页默认展示未来第 3 个月，数据库按月份分表存储，导致「编辑了但看不到效果」。

调整（`apps/admin/src/pages/DiscoveryContentPage.tsx`，纯前端）：

- 月份默认值由当月改为未来第 3 个月，与小程序首页 `monthOffset(3)` 对齐。
- 月份由裸输入框改为快捷选择器，选项为未来 1-4 个月，第 3 个标注「小程序首页默认」。
- 编排表补全赛事日期、城市、报名状态列，便于判断赛事是否适用。
- 焦点赛事缺图时显示红色「缺焦点图」标签，存在缺图项时禁用保存并给出提示，避免提交后才发现 400。
- 顶部 Alert 补充小程序首页对应月份的说明。

## 四、赛事图片直接上传

### 后台入口

- 赛事列表（`EventsPage.tsx`）操作栏新增「图片」按钮，点击跳转至「全国发现内容 → 媒体审核」并自动预选该赛事。
- 媒体审核页（`DiscoveryContentPage.tsx`）支持通过 URL 参数 `tab=media&eventId=...` 预选赛事并切换 Tab。

### 直接上传本地图片（新增）

此前图片只能通过来源页 URL 抓取，运营拿着本地图片文件无法上传。本次新增直接上传能力：

- 后端新增 `POST /api/admin/media-assets/upload`：前端将图片转 base64 放入 JSON（`imageBase64`），后端复用现有 `validateImagePayload`/`mediaSha256`/`imageDimensions`/`eventMediaClient.upload` 链路，零新依赖。
- 该接口在全局 `express.json({limit:'1mb'})` 之前单独挂载 `express.json({limit:'12mb'})`，容纳 base64 图片体积。
- nginx 为 `/api/admin/media-assets/upload` 单独配置 `client_max_body_size 12m`，其余接口仍保持 16k。
- 前端媒体审核页新增「直接上传本地图片」区块：antd `Upload` 控件（限 jpg/png/webp，8MB），选图即时预览，填署名后上传。
- 上传图来源标注为「本地上传:{文件名}」，`sourcePageUrl` 填占位值，与 URL 抓取的图区分，便于溯源。
