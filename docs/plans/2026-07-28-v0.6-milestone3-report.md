### 2. 雷达页纯逻辑（`apps/miniapp/utils/radar.ts`，+11 测试）
- `buildRadarQuery`：全偏好 cities/distances/focusTags 逗号分隔，空维度省略，含 windowDays/campaign/limitPerGroup。
- `toDisplayGroups`：四组按优先级映射为有序展示分组，过滤空组；**无偏好时 matched 组显示"近期值得关注"**（不伪装个性化）。
- `hasNoPreferences` / `radarTotalCount` / 分组标题常量。

### 3. 雷达页（`pages/radar/index`，新增 4 文件 + app.json 注册）
- **标题/副标题**："未来 90 天赛事雷达" / "大湾区赛事持续核验中，报名信息请前往官方确认"。
- **城市/距离/关注点多选**（chip UI，复用偏好页选项数组），应用/清空。
- **四组展示**：即将截止 / 本周开报 / 最近确认的变化 / 更符合你的偏好；卡片复用 `<event-card>`，`showFavorite="{{false}}"`。
- **matchReasons → 卡片 reasons、badges → tags**（复用现有卡片渲染展示匹配理由与 badge）。
- **空状态 + 无偏好引导**（"未设置偏好，显示近期值得关注赛事。点此设置…"，不伪装推荐）。
- **固定合规文案** footer（`AI 整理，仅供参考，报名以官方为准。`）。
- **渲染成功后埋点 `viewed_radar`**（§8.2：页面真正渲染成功后再发送）。
- **Campaign 参数贯穿**：onLoad 读取 `campaign/cities/distances` 查询参数，记入归因与分享路径。
- **分享**：`onShareAppMessage`/`onShareTimeline` 携带当前筛选 + campaign 的雷达路径。
- app.json 注册 `pages/radar/index`（**不新增 Tab**，按 §6.1）。

### 4. 首页改造（`pages/home/index`，§7）
- **读取全部城市、距离、focusTags**（不再只用 `cities[0]`/`distances[0]`）。
- **调用雷达预览**（`limitPerGroup=3`，windowDays=90）；映射四组到首页三段（本周开报+更符合偏好→优先关注 / 即将截止 / 最近确认变化），收藏态合并。
- **失败回退**：雷达接口失败/空时回退到现有 `getEventsWithFallback` + `groupHomeEvents`，**不白屏**。
- **无赛事/无偏好**：仍走回退路径（不伪装个性化）。
- **雷达入口**：新增"查看未来 90 天赛事雷达"卡片入口，携带当前偏好跳转。
- 保留现有视觉语言（theme-shell、section、event-card、loading/empty-state）。

## 风险与边界
- **雷达接口失败回退**：首页 `loadRadarPreview` reject（含空结果 `radar-empty`）即回退现有逻辑，保证不白屏；雷达页本身失败显示错误态 + 重新加载。
- **复用 event-card**：雷达卡片 `showFavorite=false`（无收藏按钮，避免无 isFavorite 时误触）；matchReasons/badges 通过字段映射复用卡片 reasons/tags 渲染。
- **开关默认关闭**：`RADAR_FEATURE_ENABLED=false` 时 `/api/radar` 返回稳定空结构 → 首页 `loadRadarPreview` 因空 reject → 回退现有赛事逻辑，首页行为与改造前一致。
- **回滚**：前端回滚还原 home/index.* 与 api.ts/share.ts，删 pages/radar + utils/radar；无 schema 变更。
