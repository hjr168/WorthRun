## 已完成

### 1. 雷达分组判定与确定性匹配分（shared 纯函数，`packages/shared/src/radarGroups.ts`）
- **四组判定纯函数**（交接文档 §6.4）：
  - `isSignupOpening`（本周开报）：signupStartAt 未来 7 天内 / signup_open 且过去 7 天内；
  - `isClosingSoon`（即将截止）：closing_soon / signup_open 且 deadline 未来 7 天内；
  - `isRecentlyChanged`（最近确认变化）：hasRecentAppliedChange（路由侧按 applied+14天预计算）；
  - `decidePrimaryGroup`：按优先级 即将截止 > 本周开报 > 最近确认 > 更符合偏好。
- **确定性匹配分**（§6.4 评分表）：城市+30 / 距离+25 / 关注点每+10最多+30 / priority+10 / watch+3 / 紧迫+5 / verified+10 / official·trusted+5 / 未来30天+5。
- **matchReasons**：只由实际字段生成（"城市符合你的偏好""半马 距离""关注点：新手友好"），**不输出"推荐报名/一定值得跑"等替用户决策的结论**（已断言测试）。
- `signupUrgency`（紧迫度，排序 tie-break）、`buildBadges`（次级命中 badge，不与主分组重复）。
- 无偏好时 score=0、reasons=[]（不伪装个性化）。
- **23 个单元测试**全过。

对应文件：`packages/shared/src/radarGroups.ts`、`packages/shared/src/radarGroups.test.ts`、`packages/shared/src/index.ts`（re-export）

### 2. 雷达查询服务（`apps/api/src/radarService.ts`）
- **复用 `buildPublicEventWhere` 语义**（published + 大湾区 + 未来），叠加窗口 `eventDate > today AND <= today+windowDays`。
- **多城市 OR**（`city IN [...]`）、**多距离 OR**（`AND of has(d)` 实现数组内 OR）、**城市×距离 AND**（where 默认 AND）。
- **30-180 天窗口**（clamp）、**limitPerGroup 1-30**（clamp，默认 20）。
- **单次查询取齐字段**（含 changeAlerts applied 预取），**避免 N+1**。
- **主分组去重**：同一赛事只在一个主分组（按优先级处理 + seen Set）。
- **稳定排序**（§6.4）：匹配分降序 → 紧迫度降序 → 日期升序 → ID 升序。
- **Campaign 归因解析**（无效 code 不影响查询）。
- **不泄露私有字段**：只投影公开字段，不返回 admin 备注/候选/原始 payload/未处理告警/用户标识/私有 URL。

### 3. 公开雷达路由（`GET /api/radar`）
- **无需登录**，不因无用户身份拒绝请求。
- **开关关闭**返回 `radarDisabledResponse()` 稳定空结构（首页可回退，不白屏）。
- 查询参数白名单解析（城市/距离/关注点）、窗口/limit 钳制；**超长参数 400**（schema max 边界）。
- 响应含 `generatedAt / window / filters / campaign / total / groups / complianceNotice / officialActionText`，与 §8.1 对齐。
