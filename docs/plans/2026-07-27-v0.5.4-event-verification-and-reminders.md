# WorthRun V0.5.4 赛事可信核验与提醒灰度上线实施计划

## 目标

打通“人工核验赛事 -> 用户订阅 -> 微信发送 -> 后台审计 -> 失败处理”，保持单个
PM2 API 进程，并将一次性提醒任务的 Node heap 限制为 96MB。

## 实施任务

### 1. 赛事可信核验

- 为赛事增加可选的精确开赛时间 `eventStartAt`。
- 新增赛事核验预览、列表、摘要和最多 20 场批量应用接口。
- 核验只接受未来大湾区、官方或可信来源、来源摘要已发布且未过期、无开放变更告警的赛事。
- 核验成功写入 `infoStatus=verified`、`sourceCheckedAt`、字段可信状态和管理员操作日志。
- 普通编辑禁止直接升级为已核实；关键字段变化自动降级并暂停未发送提醒。
- 后台新增“赛事核验”入口，支持问题筛选、提醒资格预览和快照冲突提示。

### 2. 精确提醒资格

- 赛前提醒要求真实 `eventStartAt`，在赛前 7 天北京时间 09:00 触发。
- 报名未开始要求真实 `signupStartAt`；报名中或即将截止要求真实 `signupDeadline`。
- 微信 `time` 字段统一使用北京时间 `YYYY-MM-DD HH:mm`。
- 缺少时间、信息降级、来源冲突、赛事下架、用户禁用或临近比赛时不得发送。
- 已发送提醒永久保持 `sent`，同一用户、赛事和提醒类型最多发送一次。

### 3. 发送可靠性与审计

- 增加轻量 `ReminderDeliveryRun` 记录，不保存 OpenID 或消息正文。
- 无到期任务时不请求微信 access token。
- 网络、HTTP 5xx 和微信系统繁忙最多重试 3 次；终止错误不循环重试。
- 增加 trial-only 测试发送命令，并扩展 ready/live 两阶段预检。
- 现有维护任务清理 90 天前运行记录，不增加维护 cron。

### 4. 后台和小程序体验

- “增长与提醒”增加提醒资格、状态、授权漏斗和最近运行结果。
- 新增提醒列表，只提供查询，不提供批量强制发送。
- 赛事详情展示提醒预计时间、已开启状态和不可用原因。
- “我的提醒”显示计划时间、赛事状态和复核状态。
- 日活基线增加看到提醒、调起授权、接受授权三个匿名布尔指标。

### 5. 配置、测试和灰度

- 报名模板使用 `thing9`、`time2`、`thing3`。
- 赛前模板使用 `thing1`、`time11`、`thing5`。
- 体验版先配置 `WX_MINIPROGRAM_STATE=trial`，正式开关保持关闭。
- ECS 提醒 cron 使用 `7,22,37,52 * * * *`，避开现有赛事源任务。
- 执行全量测试、类型检查、API/admin 构建和小程序 TypeScript 检查。
- 部署前备份 PostgreSQL 并记录 SHA-256；迁移后核对用户和业务数据数量。
- 体验版使用 2-3 个测试账号完成两类真实发送，观察 48 小时后再切换正式版。

## 验收边界

- 首批至少 8 场赛事完成可追溯人工核验。
- 不使用 AI 推测时间，不自动核验、自动发布或自动订阅。
- 保留“AI 整理，仅供参考，报名以官方为准。”和“前往官方确认”。
- 不提交 `apps/miniapp/project.private.config.json`、`design/` 或 `promo/` 的现有用户修改。
