## 已完成

### 1. 数据库：3 张新表（非破坏性 migration）

新增迁移 `20260728074646_v06_growth_campaigns_visitors`（已应用，本地库 18/18），经核对**纯 CREATE TABLE / CREATE INDEX / ADD FOREIGN KEY，无 DROP/RENAME/DELETE**：

- **`growth_campaigns`**（运营渠道）：`code`（唯一，创建后不可改）、`name`、`channelType`、`partnerName`、`status`(active/paused/archived)、有效期、`createdBy`。
- **`growth_visitor_daily`**（匿名访客日聚合，幂等）：`@@unique([visitorKeyHash, activityDate])`，7 个动作布尔字段，`campaignId`/`referralShareToken`/`firstEntryPage`/`firstChannel` 归因字段，可选 `userId`。
- **`growth_visitor_event_view_daily`**（不同赛事浏览幂等事实表）：`@@unique([visitorDailyId, eventId])`，可靠计算"查看至少 2 场不同赛事"。
- 新增枚举 `GrowthCampaignType`(10 渠道类型)、`GrowthCampaignStatus`。
- `Event` 模型追加 `visitorEventViews` 反向关系。

对应文件：`packages/database/prisma/schema.prisma`、`packages/database/prisma/migrations/20260728074646_v06_growth_campaigns_visitors/migration.sql`

### 2. 匿名访客增长 service（`apps/api/src/visitorGrowth.ts`）
- **visitorKeyHash 复用现有 `userKeyHash`**（HMAC-SHA256，`USER_OPENID_HASH_SECRET`），**不存明文 userKey**（验证：库里 0 行带 `anon-` 明文前缀）。
- **幂等**：同一访客同日一行（upsert on `[visitorKeyHash, activityDate]`），重复埋点不新增独立访客。
- **三类归因分别保存**：`campaignId` / `referralShareToken` / `firstChannel`(direct)，不强求二选一；首次有效 Campaign 与首次分享 token **不覆盖**（`mergeFirstTouch` 纯函数，已单测）。
- **不同赛事浏览**：独立幂等事实表，仅 `viewed_event_detail` 带有效 `eventId` 时记录。
- **匿名后登录关联**：当日已有匿名活动补上 `userId`，而非新建第二条（不合并两个不同匿名哈希）。
- **Campaign 解析**：仅 active 且在有效期内才采纳；失效/暂停/归档/未知 code 返回 null（不归因，访问仍记录为 direct）。
- 纯函数 `resolveAttribution`/`mergeFirstTouch`/`visitorActivityDate` 独立可测（11 测试）。

### 3. Campaign service（`apps/api/src/campaignService.ts`）
- CRUD（`createCampaign`/`updateCampaign`），**code 不在 update 入参中，天然不可修改**。
- 校验：`validateCampaignCode`（复用 shared 的 `isValidCampaignCode`，6-32 位 `[a-z0-9-]`）、`validateDateRange`（开始不晚于结束）。
- `getCampaignStats(campaignId, days)`：返回 visitors/newUsers/radarVisitors/`twoPlusVisitors`/各动作用户/coreAction/转化率，**全部匿名聚合，无用户标识**。

### 4. API 路由（接入 `apps/api/src/server.ts`）
- **`POST /api/growth/visitor-activity`**（公开，无需登录）：动作映射、Campaign 归因、分享 token 校验、可选登录用户关联；**埋点失败不阻塞主业务**（catch 吞掉）；不记录 IP/Cookie/指纹。
- **Campaign 管理（管理员）**：`GET/POST /api/admin/growth-campaigns`、`GET/PATCH /api/admin/growth-campaigns/:id`、`GET /api/admin/growth-campaigns/:id/stats?days=`。创建/更新写 `adminOperationLog`。
- **`GET /api/admin/growth-funnel?days=&campaign=&source=`**：总漏斗，支持 all/campaign/share/direct 切换，每步返回 `{value, base, rate}` 分子分母。
- shared 包新增 `GrowthCampaignType`/`GrowthCampaignStatus` 类型与值数组（与 Prisma enum 对齐，沿用现有"shared 定义类型"模式）。

对应文件：`apps/api/src/visitorGrowth.ts`、`apps/api/src/campaignService.ts`、`apps/api/src/server.ts`、`packages/shared/src/radar.ts`
