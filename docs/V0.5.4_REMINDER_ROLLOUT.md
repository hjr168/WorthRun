# V0.5.4 提醒灰度上线操作单

## 体验版阶段

1. 数据库迁移后保持 `REMINDER_FEATURE_ENABLED=false`。
2. 配置两个订阅消息模板及字段，并设置 `WX_MINIPROGRAM_STATE=trial`。
3. 续费 UniCloud，并将 `UNICLOUD_SPACE_EXPIRES_AT` 更新为至少剩余 30 天的准确时间。
4. 通过 `ops/start-api-clean-env.sh` 启动 API，确认后台显示运行配置与服务器 `.env`
   一致。
5. 运行：

   ```bash
   pnpm release:preflight-v0.5.3 -- --phase=reminders --mode=ready
   ```

6. 在“赛事核验”中确认至少 2 场有真实开赛时间、至少 1 场有未来有效报名时间。
7. 先治理疑似重复的已发布赛事，存在用户关联数据时不得直接归档。
8. 使用体验版账号逐项授权；体验版请求头只对 trial 环境开放订阅，不影响正式版用户。
9. 指定已订阅记录执行真实测试发送：

   ```bash
   pnpm reminder:test-send -- --user-id <id> --event-id <id> --type <signup|race_week> --apply
   ```

## 正式启用

1. 连续观察 48 小时，确认无重复发送、模板格式错误和新增 5xx。
2. 设置：

   ```dotenv
   WX_MINIPROGRAM_STATE=formal
   REMINDER_FEATURE_ENABLED=true
   ```

3. 运行：

   ```bash
   pnpm release:preflight-v0.5.3 -- --phase=reminders --mode=live
   ```

4. 确认 `live` 预检零阻塞后，安装 `ops/cron/worth-running-reminders`。
5. 后台应在 30 分钟内出现新的提醒运行记录；即使没有到期提醒也会记录成功空运行。
6. 确认 `/var/log/worth-running-reminder.log` 已纳入 logrotate。
7. 验证 PM2 仍只有一个 API 进程，API RSS 小于 220MB，发送任务峰值 RSS 小于 120MB。

## 回退

- 立即设置 `REMINDER_FEATURE_ENABLED=false` 并移除提醒 cron。
- 不删除提醒或发送运行记录。
- 已发送记录保持 `sent`，不得重置或重发。
