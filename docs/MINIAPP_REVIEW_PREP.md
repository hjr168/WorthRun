# 小程序提审准备

本文档用于《哪场值得跑》体验版和微信小程序提审前准备，不构成法律意见。实际类目、域名和隐私配置以微信公众平台当前规则为准。

## 1. 小程序定位说明

哪场值得跑是面向跑步爱好者的跑步赛事信息整理与赛前决策参考工具，帮助用户查看公开赛事信息、收藏关注赛事、记录跑赛偏好，并在报名前前往官方渠道确认信息。

## 2. 服务类目建议

具体服务类目需以微信公众平台当前可选类目为准。可优先查看体育、生活服务、工具、信息查询等相关类目，不要把本文档中的建议写成唯一答案。

## 3. 域名配置

- API 必须使用 HTTPS。
- 需要在微信公众平台配置 request 合法域名。
- 提审配置不要使用 localhost。
- 提审配置不要使用局域网 IP。
- 提审配置不要使用 HTTP。
- 体验版和正式版使用不同环境时，需要确认小程序配置与微信公众平台域名配置一致。

## 4. 用户数据说明

V0.5.3 起接入微信用户体系（功能开关默认关闭，开启后生效）：

- 不强制微信登录，网络失败或开关关闭时仍可匿名浏览。
- 使用 `wx.login` 静默绑定微信用户；OpenID 在服务端 AES-256-GCM 加密保存，后台默认脱敏，不保存 `session_key`。
- 匿名 `userKey` 仅用于过渡期关联本机历史偏好、收藏、赛事选择和反馈；绑定后只保留 HMAC 哈希别名。
- 用户主动填写的昵称和头像仅用于本人“我的/个人资料”页和后台，不向其他用户展示；头像经 UniCloud 直传，ECS 只签发一次性凭证。
- 匿名赛事选择（想跑 / 观望 / 已报名）只公开展示聚合数量，不展示参与者。
- V0.5.4 赛事提醒为用户主动订阅的一次性订阅消息，默认关闭，按灰度开启；不含报名交易。
- 不采集真实姓名。
- 不采集手机号。
- 不采集身份证。
- 不采集定位。
- 反馈内容由用户主动填写。

## 5. 隐私政策注意事项

提审前需要人工准备：

- 隐私政策。
- 用户数据用途说明。
- 反馈内容处理说明。
- 收藏和偏好数据说明。
- 联系方式或数据删除方式。

## 6. 官方入口说明

- 小程序不提供官方报名闭环。
- 不使用报名直达文案。
- “前往官方确认”仅复制官方链接。
- 用户需要到官方渠道确认信息。
- 赛事信息以官方为准。

## 7. 审核说明建议文案

可复制到微信审核备注，并按实际情况微调：

```text
本小程序为跑步赛事信息整理与赛前决策参考工具，不提供赛事报名交易服务。赛事详情页展示“AI 整理，仅供参考，报名以官方为准”提示；“前往官方确认”仅复制公开官方链接，用户需前往官方渠道确认赛事信息。当前版本不含社区、评论、用户发帖、付费报名、分享奖励等功能。
```
