# 大湾区赛事雷达冷启动增长运营

> V0.6 运营工作目录。模板可提交，真实联系人数据不提交。

## 目录结构

- `templates/` — 可提交的空白模板（触达、访谈、周报、赛事供给盘点）
- `*.local.csv` / `*.local.md` — 运营者本地真实数据（已 gitignore，不提交）
- `private/` — 私人联系方式、跑群成员名单等（已 gitignore，不提交）

## 核心纪律（不可违反）

1. **只用公开资料**建立渠道名单，不抓取或购买私人联系人。
2. **私人联系方式**（微信号、手机号、群成员名单）只在本地 `private/` 保管，不提交 Git，不写入 Campaign 的 `partnerName`。
3. **每次触达必须绑定 Campaign code**，以便归因"哪个渠道带来有效访客"。
4. **不群发骚扰**，每天联系 4-5 个公开渠道，提供对其用户有用的赛事清单。
5. 成功标准是"有效选赛"（查看两场以上、设置偏好、核心动作、分享），**不是分享次数或访问量**。

## 模板用途

| 模板 | 用途 |
|---|---|
| `outreach-template.csv` | 渠道触达记录（联系了谁、是否回复、是否转发、Campaign code） |
| `interview-template.md` | 跑者访谈记录（三个核心问题 + 拒绝原因） |
| `weekly-review-template.md` | 周报（必须回答 7 个问题） |
| `event-supply-audit-template.csv` | 赛事供给盘点（按城市的未来 90/180 天库存与缺口） |

## 四周节奏

- 每天 30-60 分钟，4-5 个触达；
- 每周二/四/日各一张主题雷达分享卡（本周开报 / 城市雷达 / 半马全马清单）；
- 每周至少 5 名真实跑者访谈；
- 每周一次复盘（用 `weekly-review-template.md`）。

## 与代码的关系

- Campaign 在管理后台「增长渠道」页创建，code 复制到触达记录的 `campaign_code` 列；
- 后台「增长漏斗」可按 Campaign/分享/direct 查看分子分母；
- 这些模板是人工运营产物，**不替代**产品代码或真实数据。
